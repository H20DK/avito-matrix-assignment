# avito-matrix-assignment

Реализация асинхронной библиотеки для скачивания матрицы и обхода её по спирали против часовой стрелки.

## Ссылка на задание
[GitHub: avito-tech/python-trainee-assignment](https://github.com/avito-tech/python-trainee-assignment)

## Что сделано
- Реализована функция `get_matrix` с использованием `httpx`
- Написан парсер текстового формата матрицы
- Реализован алгоритм обхода против часовой стрелки
- Добавлена обработка сетевых ошибок и ошибок сервера
- Написаны тесты для проверки логики

## Что не сделано
- Не реализовано кэширование результатов.
- Не добавлено сложное логирование.

## Как запустить
1. Создайте и активируйте виртуальное окружение: для Windows: `python -m venv .venv ` `.venv\Scripts\activate` , для macOS или Linux `source .venv/bin/activate`. Выберите это окружение в VS Code.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите тесты: `pytest`

## Как проверяли
Проверка осуществлялась через запуск локальных тестов `pytest` и ручную проверку ответа от тестового URL Авито.
